# 검증 기록

2026-09-22, 설치된 Google Chrome과 Playwright로 검증.

- 구문 검사 통과. 거리·정지·객차 간격·폐곡선·선로와 지형의 관계를 검사하는 단위 테스트 5개 통과.
- 데스크톱 1440×900, 모바일 375×812 렌더를 캡처하고 직접 확인.
- 재생·정지, 속도, 3가지 시간대, 추적·자유 시점, 확대·축소·초기화, 방향키와 Space, 소리 켜기·끄기 통과.
- 모션 감소 설정의 정지 시작과 모바일 가로 오버플로 없음 확인.
- PNG 실제 다운로드 및 MP4 실제 다운로드 확인. 최종 샘플은 H.264, 1440×900, 약 12초.
- 브라우저 JavaScript 오류와 WebGL 셰이더 오류 없음.
- 로컬 모듈 및 SVG 아이콘 참조 일치. 소스에서 API 키·비밀값·동적 코드 실행 없음 확인.
- 디자인 검사 ERROR 0. 메타 색상 및 직접 만든 기하 아이콘 출처 표기에 대한 WARN만 있음.
- 배포 빌드 통과. Three.js 엔진 자체의 500kB 초과 청크 경고가 있으며 gzip 크기는 약 144kB.

모바일 검증은 Chrome의 모바일 뷰포트·터치 에뮬레이션으로 진행했다. 실제 휴대전화 장비에서의 프레임 속도는 측정하지 않았다. 시스템 내부의 모듈·제어 상태·저장 결과는 일관된다.
