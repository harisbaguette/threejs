# 타인의 아침 — Another Morning

Three.js 기반 빙의·거울·일상 체험 프로토타입. 남성 도윤(29세)으로 아파트를 걷다가 여성 서연(28세)에게 빙의하고, 다른 몸으로 아침을 경험합니다. 두 인물은 가상의 성인입니다. 서연은 한국인이라는 설정이며 현재 외형은 기존 MetaPerson 샘플을 활용한 임시 모델입니다.

## 실행

```sh
cd 04-another-morning
npm install
npm run dev
```

http://127.0.0.1:5176/ 에서 실행합니다. 상위 폴더에서는 `npm run dev` 또는 `npm run dev:04`.

## 플레이

1. **아침 시작하기**를 누르면 남성 도윤으로 시작합니다.
2. 서연에게 다가가 **E / 빙의하기**를 누릅니다.
3. 전신 거울에서 바뀐 모습을 확인합니다. 전신·얼굴 확대와 미소를 지원합니다.
4. 옷장에서 색상 조합 선택, 커피 머신 작동, 휴대폰 메시지에 답장, 창가에서 아침 감상.
5. 커피 테이블의 펜던트에서 남성으로 돌아올 수 있습니다. 경험 기록은 유지됩니다.

| 조작 | 동작 |
|---|---|
| WASD / 방향키 | 카메라 기준 이동 |
| Shift | 빠르게 걷기 |
| 화면 드래그 | 시점 회전 |
| 마우스 휠 | 3인칭 거리 조절 |
| E | 가까운 대상 상호작용 |
| V | 1인칭 / 3인칭 |
| J | 오늘의 기록 |
| P | 3D 화면 PNG 저장 |
| Esc | 일시정지 / 메뉴·거울 닫기 |

모바일에서는 이동 버튼과 화면 드래그를 사용합니다. 진행, 정체성, 옷 색상, 답장, 시점은 브라우저에 자동 저장됩니다. 새로 열면 **지난 아침 이어하기**로 복원합니다. 좌표는 저장하지 않고 안전한 시작 위치에서 재개합니다.

## 구현 범위와 한계

- 실제 골격 애니메이션, 충돌, 시점 조작, 거리 기반 상호작용, 빙의 페이드.
- `Reflector`로 플레이어를 실시간 반사하는 거울. 1인칭에서 숨기는 머리도 반사 카메라에는 보입니다.
- 옷장은 기존 의상의 두 가지 **색상 조합**을 변경합니다. 다른 옷 메시를 입히는 기능은 아닙니다.
- 커피는 머신 작동 시간과 김 연출, 휴대폰은 답장에 따른 대화, 창가는 짧은 내레이션입니다. 마시기·외출·타인과의 실시간 대화 애니메이션은 구현하지 않았습니다.
- 인물 외형은 임시 모델입니다. 피부 텍스처·표정·흑갈색 헤어·몸과 의상에 함께 적용한 체형 보정은 있지만, **요청한 한국인 미녀의 실사급 얼굴·글래머러스한 체형을 완성한 모델은 아닙니다.** 이를 충족하려면 적합한 라이선스의 전용 얼굴·헤어·체형·의상 모델 제작 또는 도입이 필요합니다.
- 현재 여성 로더는 MetaPerson의 `Head`, `Hips`, `Spine` 등 뼈 이름을 사용하며 남성 모델의 애니메이션을 변환합니다. 임의의 GLB를 파일 이름만 바꿔 넣는 것은 지원하지 않습니다.
- 건물·소품은 코드로 만든 공간이며 실사 스캔이나 서울 실측 지도가 아닙니다.
- 인물 에셋은 전부 로컬에 있으며 실행 중 외부 CDN에 의존하지 않습니다. 출처와 고지는 [ASSETS.md](ASSETS.md).

## 검증

```sh
npm test
npm run build
# 개발 서버를 켠 상태, 설치된 Chrome 사용
npm run test:e2e
```

단위 검사는 진행 조건, 손상된 저장 데이터, 충돌 경계와 관통 방지를 검사합니다. 브라우저 검사는 실제 키보드·포인터 입력, 빙의, 거울, 옷장, 모든 체험, 저장 복원, 사진 다운로드, 모바일 조작을 확인하고 `test-results/`에 스크린샷을 남깁니다.

개발 서버의 `?test` 주소에서만 `window.__morning` 테스트 도구가 제공되며 프로덕션 빌드에는 포함되지 않습니다.
