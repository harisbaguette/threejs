# 창가 체험 — 검증 기록

검증일: 2026-09-22. 구현 범위: `02-shiosai`의 기본 창가 체험과 기존 승강장 연결.

## 무엇을 바꿨는가

이전 장면의 나무·산·집을 절차적으로 조금씩 고치는 방식만으로는 사용자가 요구한 실사급 밀도를 충족하지 못했다. 기본 감상을 창가 시점으로 다시 구성하고 생성 사진을 얕은 깊이 메시로 투영했다. 따뜻한 역의 빛과 차가운 바다를 함께 두고, 실제 3D 창틀·유리 굴절·김·손으로 닦은 흔적·시간대 전환·스테레오 환경음을 붙였다. 나에게 남길 한 줄과 풍경을 하나의 엽서 파일로 저장할 수 있다.

기본 창가는 2.5D 합성 체험이다. 창밖의 전철·건물을 모든 방향에서 볼 수 있는 실사 3D 모델은 아니다. 기존 자유 시점 3D 승강장은 `station.html`에 보존했다. 구매 의향이나 유료 전시의 사업성을 측정하지 않았다.

## 실제 화면 비평과 재작업

1. 첫 렌더의 빗방울 하이라이트가 흰 먼지처럼 보였다. 밝기를 낮추고 굴절 중심으로 바꿨다.
2. 외부 SVG 심벌의 루트 스타일이 `<use>` 안에 전파되지 않아 아이콘이 검게 보였다. 소비하는 SVG에 stroke/fill을 명시했다.
3. 모바일 중앙 크롭이 바다를 거의 가렸다. 모바일 투영 구도를 바다 쪽으로 옮겼다.
4. 모바일 제목이 전철 정면을 가렸다. 제목을 하늘 쪽으로 옮기고 겹치는 안내 문장을 덜었다.
5. 엽서 미리보기의 cover 크롭이 실제 다운로드와 달랐다. contain으로 전체 화면을 보존하도록 맞췄다.
6. 모션 감소의 초기 정지가 소리도 막았다. 진입 클릭은 소리를 켜고 시각적 정지만 유지하게 고쳤다.

## 실행 비용

로컬 Chrome, 1440×900, 120프레임 표본:

- 프레임 간격 중앙값 16.7ms, p95 16.8ms.
- 드로 콜 16, 삼각형 23,402.
- 모션 감소 및 정지 상태에서 변화가 없을 때 추가 렌더 0.

새 구성은 창가 시점에 맞춘 사진 투영이므로 기존 전체 3D 세계와 동일한 자유도에서의 성능 비교는 아니다. 기기별 결과를 보장하지 않는다.

## 저장 파일 검증

- `exports/window-postcard.png`: 1800×1440 PNG. 실제 이미지를 열어 한글·날짜·풍경·여백을 확인했다.
- `exports/window-preview.mp4`: 11.998초, H.264 1600×1000, 평균 약 30.02fps, AAC 48kHz 스테레오, 15,475,710바이트.
- ffmpeg로 영상 7초 프레임을 디코딩해 확인했다. ffprobe로 영상과 음성 트랙을 확인했다.
- 음성 평균 -22.0dBFS, 최대 -5.8dBFS. 녹음이 비어 있지 않으며 샘플에서 디지털 클리핑이 없었다. 음향 장치별 청감 테스트는 하지 않았다.
- 정지 상태에서 녹화를 시작해도 영상이 움직이고 녹화 후 원래 시각 정지 상태를 유지했다.
