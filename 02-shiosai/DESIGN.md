# 潮騒 — 비가 머문 역

## 사용자 의도

기존 작품은 "굉장히 좋군"이라고 평가했다. 첫 작품을 보존하고 여러 독립 프로젝트를 만들고 싶어 한다. 새 작품은 블록이나 로우폴리 느낌을 벗어난 리얼월드·실사·일본·감성이 핵심이다.

## 장면

비가 갠 저녁, 일본의 가상 해안역 시오사이. 사람 눈높이의 45mm 사진을 떠올리는 구도. 왼쪽 낡은 승강장과 처마, 중앙의 둥근 차체의 녹색 전철, 오른쪽 잔잔한 바다와 멀리 겹친 산. 젖은 바닥에는 역의 따뜻한 등이 반사된다. 과장된 덩어리 나무와 면이 드러나는 지형을 사용하지 않는다.

## 시각 시스템

- 주인공은 풍경. UI는 화면 가장자리의 작은 활자와 가는 선, 여백으로 구성한다.
- 모노톤 크림 #ece9dc, 잉크 #172626, 물빛 #547879, 신호색 #c2b88b.
- 일본어는 역명·행선판 등 현장 간판에만 쓰고 조작은 한국어로 제공한다.
- 물리 기반 재질, 실제 촬영한 CC0 아스팔트·콘크리트 재질 및 HDR 조명, 금속과 유리의 반사, 사진 같은 노출과 미세한 그레인.
- 실사에 가까운 분위기가 목표다. 영화·사진과 동일한 품질이라고 과장하지 않는다.

## 조작

세 가지 촬영 시점, 해질녘·푸른밤, 비 켜기, 열차 재생·정지, 소리, 화면 요소 숨기기, 사진과 12초 영상 저장. 모바일·키보드·모션 감소 설정을 지원한다.

## 검증

1440×900, 375×812에서 직접 렌더를 확인한다. 첫 작품 이동 후 실행도 검사한다. 저장 결과는 실제 파일을 열어 검증한다.

## 자기비평과 보완 — 2026-09-22

초기 버전은 실사급 요구에 미달한다. 창문에 그린 그림, 매끈한 단색 구조물, 평평한 선로, 일률적인 직선 풀, 지붕의 큰 조명 번짐이 3D 모형 느낌을 만든다. 밤에도 동일한 해 원판이 남는 것은 시간대 표현 오류다. 기능 검사 통과를 시각적 완성의 근거로 삼은 평가도 부족했다.

차창 뒤에 실제 좌석·손잡이·운전실을 만들고 유리를 투명하게 바꾼다. 자갈·목재의 촬영 재질, 마모와 녹의 미세한 차이, 처마의 골과 프레임으로 표면과 구조를 구분한다. 지붕의 과한 반사를 낮추고 기본 구도에서 바다와 전철의 비중을 높인다. 밤에는 해를 없애고 더 차가운 주변광과 객실 조명으로 명암을 나눈다. 반복되는 풀은 곡선과 방향·색 차이가 있는 군락으로 교체한다.

작은 화면에서 풍경을 가리는 장식을 덜고 모든 버튼의 최소 터치 영역을 44px로 맞춘다. 812×375 가로 화면의 버튼 잘림, 카메라의 지면 관통, 정지 상태에서 불필요한 연속 렌더도 실제 동작으로 검증한다. 수정 전후 동일 해상도 캡처와 수치를 남긴다. 구현 범위는 `02-shiosai`다.

## 창가 체험 재설계 — 2026-09-22

사용자의 최종 지시: “그니까 내가 원하는대로 어떻게든 만들라고”. 기존 수정의 재질 보강으로는 실사·일본·감성을 충족하지 못했다. 창밖의 촘촘한 실제 세계 표현과 창가에 앉아 있는 감각을 중심으로 매체와 구도를 다시 정한다. 범위는 `02-shiosai`이며 다른 프로젝트는 건드리지 않는다.

- 기본 진입은 `index.html`의 창가. 기존 자유 시점 3D 승강장은 `station.html`로 유지한다.
- 생성 사진 2장을 얕은 깊이의 Three.js 메시 위에 투영한다. 실제 촬영이나 전체 3D 공간이라고 소개하지 않는다. 먼 바다와 젖은 승강장에는 영역별로 작은 움직임을 주고, 근경의 창틀은 별도 3D 메시로 만든다.
- 유리의 흐르는 물방울·고인 작은 방울·굴절·희미한 객실 반사·가장자리 김을 실시간 셰이더로 계산한다. 드래그하면 김이 걷히고 서서히 돌아온다. 키보드 C 및 설정 버튼으로 같은 기능을 제공한다.
- 한 화면에 풍경이 주인공. 진입 전 짧은 제목과 ‘창가에 앉기’, 진입 후 시간대 2개와 소리·정지·엽서만 표시한다. 추가 조작은 설정 안에 둔다.
- 객실의 낮은 진동, 처마와 유리에 맺히는 비, 오른편의 낮은 파도, 멀리서 드물게 들리는 자체 제작 4음 차임. 소리는 진입 클릭 이후에만 시작한다. 음량 조절·음소거·숨긴 탭 일시정지를 제공한다.
- 마음에 남는 한 줄을 풍경과 함께 1800×1440 엽서로 저장한다. 글은 브라우저 localStorage에만 저장하며 외부 전송하지 않는다. 브라우저에서 소리를 포함한 12초 영상도 저장한다.
- 팔레트: 잉크 #101b20, 패널 #162229, 글자 #f3efe4, 보조 #c4c7c5, 황동 #d4b992. 따뜻한 역 조명과 바다의 청색을 그대로 살리고 UI는 가장자리의 작은 활자와 선으로 제한한다. 풍경의 저녁 시간대 때문에 어두운 UI를 사용한다.
- 타이포: 로컬 Mincho/Batang 계열은 장소의 역명·제목에만, 조작은 시스템 한국어 산세리프. 글꼴·분석 등 외부 네트워크 의존 없음.
- 모션 감소에서는 풍경과 물방울을 정지하고 시점 추종·느린 시간대 전환을 끈다. 기록 버튼은 사용자의 명시적인 영상 요청이므로 기록 중만 움직인다.

판정은 실제 1440·375 화면과 조작에서 수행한다. 결제 의향을 검증했다고 주장하지 않는다. 생성 배경·제한된 시차라는 매체 범위를 README에 명시한다.

검수 후 작은 주변 활자(역명 보조 영문·시간·장식 문장·힌트)는 10~13px로 유지하되, 주요 시간대/저장 조작은 데스크톱 14px, 모바일 12~13px 및 최소 44px 터치 영역으로 구성했다. 긴 본문을 보여주는 화면은 없다. 입력은 16px. 체크박스의 24px 곡률은 네이티브 스위치 형태와 클릭 영역을 위한 것이다. 세부 캡처·검증·매체의 한계는 `WINDOW-REVIEW.md`에 기록한다.
