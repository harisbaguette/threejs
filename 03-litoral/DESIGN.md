# LITORAL

해안 마을을 직접 걸어 다니는 3인칭 탐험 게임. 사진 기반 재질과 실제 인체 애니메이션,
실시간 물 반사, 햇빛과 접촉 그림자가 화면의 중심이다. UI는 장면을 가리지 않는 게임 HUD다.

- 분위기: 지중해 해안의 늦은 오후. 청록 바다, 따뜻한 석재, 녹색 셔터와 흙빛 지붕.
- 화면: 전체 WebGL 장면, 좌상단 작은 워드마크, 우상단 탐험 진행도, 하단 조작 안내와 미니맵.
- 진입: 게임 장면 위 왼쪽 타이틀과 시작 버튼. 시작하면 타이틀은 사라진다.
- 글꼴: 시스템 sans-serif, 제목 Georgia. 영문 게임명과 한국어 조작 안내.
- UI 토큰: paper #f5f1e7, ink #18332e, muted #b8c7bb, accent #ead9a5.
- 어두운 반투명 표면은 밝은 야외 장면 위 텍스트 대비를 유지하기 위해 사용한다.
- 44px 이상 터치 영역. 모바일은 왼쪽 이동 패드와 오른쪽 드래그 시점 조작.
- 디자인 검색기의 일반 웹 랜딩 구성은 게임 목적에 부적합하여 사용하지 않는다.
- 주요 기능: 이동/달리기/점프, 카메라 회전, 장소 4곳 기록, 지도, 저장, 사진 저장, 오디오.
- 검증: 데스크톱/모바일 실제 렌더, 이동과 충돌 및 점프, 일시정지, 저장 복원.
