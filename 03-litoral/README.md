# LITORAL — 바다 곁을 걷다

Three.js로 만든 3인칭 해안 마을 탐험 게임. 애니메이션이 있는 캐릭터를 움직이며
산책로, 선착장, 카페, 분수 광장, 등대를 돌아다닙니다.

여성 **SOFIA**가 기본 캐릭터입니다. 시작 화면의 **함께 걸을 사람** 또는 게임 중 오른쪽 위
사람 아이콘에서 여성·남성을 선택합니다. 전신/얼굴 확대와 드래그 회전으로 미리 본 뒤
**이 캐릭터로 걷기**를 누르면 적용됩니다. 위치와 탐험 기록은 유지되며 선택은 자동 저장됩니다.
여성 모델에는 고해상도 얼굴·피부·의상 재질, 머리카락, 눈 깜빡임,
골격에 맞춰 변환한 걷기·달리기·점프 애니메이션을 적용했습니다.

```sh
npm install
npm run dev
```

http://127.0.0.1:5175 에서 실행됩니다. 상위 폴더에서는 `npm run dev:03`.

| 조작 | 기능 |
|---|---|
| WASD / 방향키 | 카메라 기준 이동 |
| Shift | 달리기 |
| Space | 점프 |
| 화면 드래그 / 마우스 휠 | 시점 회전 / 확대·축소 |
| E | 가까운 장소 기록 |
| M | 지도와 발견 목록 |
| P | 게임 화면 PNG 저장 |
| Esc | 일시정지·그래픽 품질·감도 |

모바일에서는 왼쪽 조이스틱으로 이동하고 화면 오른쪽을 밀어 시점을 돌립니다.
버튼으로 달리기·점프·장소 기록을 할 수 있습니다. 진행도와 위치는 브라우저에 자동 저장됩니다.
자연 소리는 오른쪽 위 스피커 버튼으로 켭니다.

물 반사, HDR 환경광, PBR 촬영 재질, 실시간 그림자, 애니메이션 블렌딩,
충돌과 점프, 추적 카메라를 구현했습니다. 높은 그래픽 품질에서는 SSAO를 추가합니다.
Three.js 기반의 소규모 탐험 데모이며, 건물 안으로 들어가거나 수영하는 기능은 없습니다.
마을은 직접 모델링한 가상 공간이며 사진측량으로 복제한 실존 도시는 아닙니다.

```sh
npm run build
npm test
# 개발 서버를 켠 상태에서, 설치된 Google Chrome 사용
npm run test:e2e
# 캐릭터 선택/이동만 검증
npm run test:characters
```

개발 모드의 `?test` URL에만 통합 테스트를 위한 위치 이동 도구가 제공됩니다.
프로덕션 빌드에는 이 도구가 포함되지 않습니다.

에셋이 모두 `public/assets`에 포함되어 실행 중 외부 CDN에 접속하지 않습니다.
재질·모델 출처는 [ASSETS.md](ASSETS.md)를 참고하세요.
